# lens - low level execution nes system
## What is lens?
lens is a nes emulator implemented in rust, running directly in your browser,
Written in rust.
## What's different from other emulators?
lens provides a built-in debugger with a rewind & snapshot system
which, provides a place to experiment, rewind, save, etc
